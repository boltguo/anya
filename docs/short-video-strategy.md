# Anya 短视频矩阵与运营策略 (Short Video Strategy)

这份文档规划了如何通过短视频平台（抖音、B站、小红书、视频号等）推广 Anya Agent，将其从一个个人开源项目转化为具有影响力的产品/IP。

## 🎯 核心定位与受众差异化

Anya 兼具“硬核技术底座”与“高频实用场景”。因此，我们的短视频内容必须采用**“双轨制”**，针对两类完全不同的人群打出不同的牌：

1. **英语学习者（To C 用户）**：关心“这东西能不能帮我提分/克服哑巴英语”，不关心代码。
2. **极客与开发者（To D 开发者）**：关心“底层怎么实现的/有什么牛逼的架构设计”，讨厌营销话术。

---

## 🎬 方向一：面向英语学习者 (主打“降维陪伴”与“免费私教”)

**核心标签**：没有情绪内耗、有记忆的错题本、IELTS 降维打击。

### 爆款选题 1：不要再花一万块钱请雅思私教了
* **痛点切入**：雅思一对一口语陪练极贵，且很多人面对真人开口会有“外语羞耻症”。
* **画面展示**：左侧屏幕是人在随意地走路/喝咖啡，右侧屏幕是 Telegram 界面。展示用语音随口说一句漏洞百出的英语，Anya 秒回地道语音，并精确指出刚才的介词错误。
* **口播文案**：“我给自己写了个赛博英语私教。不按小时收费，没有情绪内耗。我结巴它不催我，我语法错了它顺手给我纠正，还自动帮我把不会的词加进生词本每天复习。”

### 爆款选题 2：普通的 AI 为什么练不好英语？因为它会“失忆”
* **痛点切入**：大多数人用 ChatGPT 陪练，聊完就忘，无法形成“测-练-评”的学习闭环。
* **画面展示**：调出 Anya 的 `study_summary`（学习报告）或直接询问 Anya：“我最近哪项最弱？” Anya 准确报出“你最近 3 篇作文从句错误率高达 40%”。
* **口播文案**：“普通的 AI 只是个陪聊，但 Anya 有一个严密的数据库（一闪而过数据库雷达图或表结构）。它清楚地知道我昨天口语连读失败了 3 次。有了记忆，它才能像真老师一样，每天针对我的弱点出题。”

### 爆款选题 3：早晨 8 点的“赛博连麦” (结合 Cron 功能)
* **痛点切入**：学习难以坚持，缺乏主动提醒。
* **画面展示**：早上 8 点，Telegram 自动弹出 Anya 的语音：“早上好，根据昨天的错题，今天我们需要复习以下两个核心词汇...”。
* **口播文案**：“你敢信吗？这是我的 AI 每天早上主动来找我上课。真正的陪伴式 Agent，绝不是等你去找它，而是它来安排你的节奏。”

## 💻 方向二：面向极客与开发者 (主打“硬核架构”与“开源精神”)

**核心标签**：拒绝套壳、ReAct 架构、极致 Token 优化。

### 爆款选题 1：受够了 ChatGPT 套壳，我手搓了一个 ReAct Agent 框架
* **痛点切入**：市面上充斥着低劣的 Prompt 拼接工具，缺乏真正的工程化架构思考。
* **画面展示**：高亮展示 VSCode 代码，重点露出 `TelegramAdapter` 的状态机设计和统一的 `tg` 工具。
* **口播文案**：“别再用几句 Prompt 骗自己是在做 Agent 了。真正的 Agent 需要极其严格的运行时约束。看看我是如何利用 TypeScript 强制大模型把含糊不清的聊天，转化为结构化的底层数据的。”

### 爆款选题 2：大模型失忆/越聊越傻怎么办？解密我的上下文压缩算法
* **痛点切入**：所有开发者都会遇到 LLM Context Window 爆炸、API 账单飙升的问题。
* **画面展示**：讲解 `contextCompressor.ts` 代码，画一个简单的滑动窗口保护头尾的示意图。
* **口播文案**：“连续和 AI 练了一个月口语，历史记录爆了怎么办？我用了一个非常鸡贼的 Hermes 同款滑动窗口压缩算法，不仅保护了 System Prompt，还把中间的废话压缩成了核心数据，API 账单直接打骨折。”

### 爆款选题 3：让大模型自己写 Cron 定时任务是什么体验？
* **痛点切入**：传统定时任务死板，Agent 主动性不足。
* **画面展示**：展示 JSON 驱动的 Cron 系统。对着麦克风说“以后每天下班提醒我复习语法”，后台 JSON 文件立刻被大模型自动更新，随后展示守护进程（Tick）自动触发的逻辑。
* **口播文案**：“给 Agent 加上时间感知能力后，它仿佛活了过来。不依赖沉重的 Celery/Redis，我用一个轻量级 JSON 加 60 秒心跳，就让大模型拥有了完美的时间观念。”

## 💡 执行与运营建议 (Actionable Advice)

1. **视觉呈现原则**：
   * 必须有**实操感**：屏幕必须展示真实交互（清晰的 Telegram 聊天界面或整洁的代码块）。
   * **快节奏**：前 3 秒抛出痛点（“还在花钱请外教？” / “别再写套壳代码了”），不拖泥带水。
2. **多平台分发侧重点**：
   * **B站**：适合方向二（硬核代码解密）和深度演示，用户喜欢弹幕探讨技术细节，极客浓度高。
   * **抖音/小红书**：适合方向一（英语提分、私教平替、情绪价值），重点包装“学外语新姿势”和“自律神器”。
3. **流量承接与转化**：
   * 如果项目开源：视频简介和评论区置顶 GitHub 链接，吸引 Star 和 PR（共建者）。
   * 如果做个人 IP：建立技术交流群或内测群，收集第一批铁杆用户的反馈，为后续可能的商业化（如提供免部署的 SaaS 版）做铺垫。
