# Upgrade / Downgrade Rules (Speaking)

## Upgrade (meet any 2)

- 3 consecutive sessions reaching 80%+ of target answer length
- Fluency/Grammar scores meet target band for 2 consecutive sessions
- Maintains coherence under follow-up pressure
- **Part 2 structure score ≥ 4/5 elements in last 2 sessions**
- **Part 3 abstraction: can discuss societal topics without falling back to personal anecdote**
- **Lexical variety: word repetition rate below 15% in last 2 sessions**

## Downgrade (meet any 2)

- Answer length consistently below 50% of target
- Same topic causes breakdown 2 consecutive times
- Errors so frequent they impair comprehension
- **Part 3 responses are exclusively personal anecdotes for 3+ sessions**

## Downgrade behavior

- Naturally switch to a lower-tier mode (e.g., Examiner Sim → Guided QA)
- Next session starts with a Shadowing warm-up
- **Never say "you've been downgraded"** — frame it as variety

## Abstraction Capability Ladder

The upgrade path for Part 3 abstract discussion:

| Level | Indicator | Action |
|---|---|---|
| 1 | Can only give personal examples | Stay in Guided QA / Cue Card, add OEE scaffolding |
| 2 | Can give opinion + personal example | Move to Role-play / Retell with abstract prompts |
| 3 | Can give opinion + explanation + example (mixed personal/societal) | Move to Examiner Sim with Part 3 focus |
| 4 | Can discuss trends, compare perspectives, evaluate policies | Exam-ready for Part 3 |

Track current level via `speaking.part3_abstraction` subcap score:
- Level 1 → score 3.0-4.0
- Level 2 → score 4.5-5.5
- Level 3 → score 6.0-6.5
- Level 4 → score 7.0+
