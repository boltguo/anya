# Mode: Lecture 讲座笔记

> Band 6.0+ | 90-180s academic audio | 2-3 speakers | 5-8 questions

Default mode for 6.0+ when no other mode is specifically called for.

## S3 — Generate Lecture

Academic topic, 90-180s, 2-3 speakers, natural pace.
For Band 6.5+, consider non-standard accent: `tts(voice:"en-GB-RyanNeural")` or `tts(voice:"en-AU-NatashaNeural")`.

## S4-S5 — Two-Listen Approach

Same as Short Clip: gist first, then detail questions.

## S6-S10 — Same as Short Clip

Error cause analysis, tiered translation, micro drill, forced redo, recording.
See `references/modes/short-clip.md` for the full pattern.

Recording variant: use `'lecture'` instead of `'short_clip'` as the prompt label.
