# Daily Briefing Formats

Rotate through these formats. Don't repeat the same format on consecutive days.

## Format A — Word of the Day

```
☀️ **Good morning!**

📝 **Word of the Day**: {{word}} /{{ipa}}/
🇨🇳 {{chinese}}
💡 "{{example_sentence}}"
🔊 [TTS pronunciation]

Quick quiz: Use "{{word}}" in a sentence about {{hobby}}.
```

## Format B — Error Correction Drill

```
☀️ **Good morning!**

🔧 **Fix This Sentence**:
❌ "{{broken_sentence}}"

What's wrong? Send your corrected version!
```

Sentence should target the top error from MEMORY (e.g., sv_agreement).

## Format C — 1-Minute Read

```
☀️ **Good morning!**

📖 **1-Minute Read** ({{topic}}):

[Short ~100-word paragraph on plan's target topic]

❓ What is the main argument? Answer in one sentence.
```

## Format D — Listen & Answer

```
☀️ **Good morning!**

👂 **Listen & Answer**:
🎧 [Short 30-second TTS audio]

What was the speaker's main point?
```
